# DigiGrow: Small Business Growth

Build a Website: DigiGrow – Digital Marketing Training for Small Businesses



Create a simple, modern, beginner-friendly web application called “DigiGrow” for my college project.



Main Purpose



DigiGrow is a digital marketing training platform designed specifically for small business owners who don't know much about digital marketing.



The website should teach users basic digital marketing through simple lessons, personalized tips based on their business type, quizzes, and a 7-day marketing challenge.



Keep the website easy to use, professional, clean, and unique. Do not make it overly complicated.



Design



- Modern and professional UI

- Responsive design for mobile, tablet, and desktop

- Clean white/light background

- Use a simple blue/purple accent color

- Rounded cards and buttons

- Use simple icons

- Smooth hover effects and subtle animations

- Large readable headings

- Beginner-friendly navigation

- Use a consistent design throughout the website



Navigation Bar



Create a navigation bar with:



- DigiGrow logo

- Home

- Learn

- My Business

- 7-Day Challenge

- Dashboard

- Login / Sign Up



After login, replace Login/Sign Up with:



- Profile

- Logout

10. Database / Authentication



Implement basic user authentication and data storage.



Store:



- User information

- Business type

- Course completion status

- Quiz scores

- 7-day challenge progress



Make sure each logged-in user sees their own dashboard and progress.



Use a simple database structure and keep the implementation beginner-friendly.



---



Important Requirements



1. The website must actually work, not just be a static design.

2. Login and registration should function.

3. Dashboard should update according to user progress.

4. Business type should control the personalized marketing tips.

5. Quiz scores should be saved.

6. 7-day challenge completion should be saved.

7. Course completion should update the progress percentage.

8. Add proper validation for forms.

9. Show friendly error and success messages.

10. Make the entire website responsive.

11. Keep the code clean and organized.

12. Avoid unnecessary advanced features.

13. Use sample/demo content where required.

14. Make the UI suitable for a college project demonstration.



Final Goal



The finished website should feel like a real beginner-friendly digital marketing training platform for small businesses.



The main unique flow should be:



Register → Select Business Type → Personalized Dashboard → Learn → Take Quiz → Complete 7-Day Challenge → Track Progress



Use the name DigiGrow throughout the website.
